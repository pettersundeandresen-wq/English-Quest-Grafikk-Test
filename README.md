# English Quest – grafisk prototype, stil B

Dette er en separat, spillbar demonstrasjon av myk, illustrert eventyrgrafikk. Den importerer en kopi av world.js fra det opplastede repositoryet, men endrer ikke hovedspillet.

## Test
Publiser som eget GitHub Pages-repository (for eksempel English-Quest-Grafikk-Test) eller kjør med lokal HTTP-server. Åpne index.html. Beveg avataren med piltaster/WASD eller joystick.

## Hva testes?
- Terreng, trær, busker, steiner, vann og bygninger i myk illustrert stil.
- En tydeligere jenteavatar.
- Zoom på 115 %.
- Visuell lesbarhet på iPad.

Oppgaver, ordbok, slott, lagring og innendørskart er ikke aktive i denne isolerte grafikkdemonstrasjonen. Når stilen er godkjent, kan renderer-integrasjonen flyttes inn i hovedspillet.
